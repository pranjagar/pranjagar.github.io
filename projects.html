Python · Quantum optimization

QAOA MaxCut simulator

A custom simulation framework for studying the Quantum Approximate Optimization Algorithm on MaxCut. Algorithmic and memory improvements increased the simulation scale from 8 to 28 qubits within a fixed 16 GB memory budget.

Numerical methods · Benchmarking

Optimization evaluation framework

A common framework for implementing and comparing Adam, BFGS, COBYLA, CMA-ES, and genetic algorithms on non-convex parameter-estimation problems.

Quantum sensing · Scientific computing

Qubit-array sensor simulations

Theoretical and computational tools for studying how networks of qubits detect patterns in discrete measurement outcomes.
